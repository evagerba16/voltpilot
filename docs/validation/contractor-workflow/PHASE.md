## Workflow Momentum (primary CTA)

Every primary CTA **advances the contractor forward** or **explains why they cannot move forward yet**. Never leave the user wondering what comes next.

| State | CTA or message |
|-------|----------------|
| Estimate complete | Create proposal |
| Proposal sent | Waiting for customer response |
| Proposal accepted | Convert to active project |
| Project complete | Review job performance |
| Missing required information | Complete required fields |

---

## The Golden Question

Before any new feature:

> *How does this help the contractor finish today's work?*

Not: technically impressive · cool AI · looks nice.

But: **Does it help someone get home earlier because paperwork got done faster?**

---

## Exit criteria

Run once after Proposals + handoffs:

1. New customer → project → estimate → send proposal → accept → job costing → analytics

Log real friction only. Then **beta**. Stop major UX work until beta feedback.
